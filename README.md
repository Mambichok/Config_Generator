# Config Generator

Приложение для создания BAT-файлов, которые запускают выбранные программы и сайты.

## Установка для Windows

1. Откройте [страницу Releases проекта](https://github.com/Mambichok/Config_Generator/releases).
2. Скачайте `ConfigGenerator_Setup_1.1.1.exe` и запустите его.
3. Завершите установку. Ярлык приложения появится на рабочем столе.

Установщик включает приложение и необходимые библиотеки: отдельно устанавливать Python не нужно. Поддерживается Windows 10/11 x64. Настройки и профили хранятся в `%APPDATA%\ConfigGenerator`.

В самом приложении есть кнопка **«ПОМОЩЬ»** с краткой инструкцией по добавлению программ, ярлыков и сайтов.

## Сборка установщика из исходников

Для сборки нужны Windows 10/11 x64, Python 3.14 x64 и Inno Setup 6.

В PowerShell из папки проекта выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\build_windows.ps1
```

Скрипт подготовит окружение сборки, создаст приложение через PyInstaller и скомпилирует установщик в папке `installer`.

Не добавляйте в GitHub личные `config.json` и профили: они исключены через `.gitignore`. Установщик рекомендуется публиковать как файл GitHub Release, а не хранить в репозитории.
